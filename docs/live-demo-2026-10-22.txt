IMPORTANT DEMO BEHAVIOR
------------------------------------------------------------

can create a real PR if no other effective policy blocks it.

development -> production should be blocked by the policy. A staging ->
production merge is conservatively refused by the execution guard because
the connector cannot atomically pin the target branch. Do not promise an
allowed staging merge. An agent refusal without a tool call does not prove
the tool guard ran; show the actual Traffic events when explaining a stage.

GMS controls its own proxy/tool path. Direct Git/GitHub operations do not pass
through GMS. Repository-wide GitHub protections are a separate control.
